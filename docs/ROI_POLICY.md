# ROI와 상태 전환

| 조건 | 상태 | 제어 |
| --- | --- | --- |
| 구역 외부 / ROI 1 | IDLE / OBSERVING | LED 및 음향 꺼짐 |
| ROI 2 체류 중 | DWELLING | 감시, 시간 누적 |
| ROI 2 사람 5초 또는 개 3초 도달 | WARNING | 65% LED, 사람 음성 또는 개 비음성 |
| ROI 3 연속 2회 감지 | CRITICAL | 100% LED, 높은 경고에 해당하는 음향 |
| 경고 중 보호 구역 밖으로 이동 | CLEARING | 1초 연속 확인 후 해제 |
| 경고 중 검출 누락 | 기존 상태 유지 | 트랙 만료 2초에 해제 |

초기값은 `config/default.yaml`에서 조정합니다. ROI가 겹치면 3, 2, 1 순으로 선택합니다. 바운딩 박스 하단 중앙 픽셀을 영상 너비와 높이로 나눠 비교하며 경계 위는 내부로 판정합니다. 하향 전환은 기본 0.2초 동안 관찰하고 상향 전환은 즉시 반영합니다. 높은 경고는 ROI 3에서 짧은 간격의 연속 확인을 통과할 때 시작합니다. 하향 이동 중 ROI 2에 남으면 높은 단계가 유지되며 보호 구역 밖에서 해제합니다.

체류는 같은 ROI 2에서 연속 관찰된 구간만 더합니다. 기본 0.6초를 넘긴 관찰 간격과 검출 누락 구간은 누적하지 않습니다. 첫 좌표가 ROI 3이면 같은 절차를 거칩니다. 트랙 만료 또는 ROI 편집 적용 시 이전 경고를 초기화합니다.

재안내 기본값은 12초 간격 1회입니다. 계속 체류하면 관리자 확인 이벤트를 한 번 기록합니다. 여러 객체 중 가장 높은 경고를 적용합니다. 같은 경고 단계는 사람 우선이 기본값이고, 같은 클래스는 낮은 추적 ID를 우선합니다. 우선 객체가 바뀌었다 돌아와도 이미 제출한 음향이 다시 나가지 않습니다.

## 카메라를 옮겼을 때

1. `--dry-run`으로 새 영상과 실제 해상도를 확인합니다.
2. 카메라 설치 각도와 자재 경계를 보고 세 다각형을 저장합니다.
3. 보호 구역 경계에 직접 서서 발 기준점과 ROI 단계, 경고와 해제를 확인합니다.
4. 구역 외 통로와 가림 구간을 통과하며 오경고와 ID 재할당을 기록합니다.
